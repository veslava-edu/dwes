    Tema 2: Ejercicios TS con Entrada de Datos

    Para realizar estos ejercicios, necesitarás una función auxiliar que permita leer datos desde la consola de forma síncrona (similar a scanf en C o input en Python), ya que readline de Node.js es asíncrono por defecto y puede complicar el aprendizaje inicial.

    Copie el siguiente bloque de código al inicio de cada solución para poder usar la función prompt:

    import * as fs from 'fs';

// Función para leer entrada de usuario de forma síncrona
// `prompt` escribe una pregunta en stdout y lee la respuesta desde stdin
// utilizando operaciones de bajo nivel de `fs`.
// - `fs.writeSync(1, question)`: escribe el texto en el file descriptor 1 (stdout).
// - Se crea un `Buffer` de 1024 bytes para recibir la entrada del usuario.
// - `fs.readSync(0, buf, 0, 1024, null)`: lee desde el file descriptor 0 (stdin)
//   y rellena el buffer; devuelve la cantidad de bytes leídos.
// - Finalmente se convierte la porción leída del buffer a string UTF-8,
//   se eliminan espacios alrededor con `trim()` y se devuelve la respuesta.
function prompt(question: string): string {
    fs.writeSync(1, Buffer.from(question, 'utf8'));
    const buf = Buffer.alloc(1024);
    const bytes = fs.readSync(0, buf, 0, 1024, null);
    return buf.toString('utf8', 0, bytes).trim();
}

    Ejercicios de Consolidación

    1) El Analizador Químico (Arrays, Tuples y Enums) | Nivel: Fácil

    Objetivo

    Practicar la definición de tipos estrictos usando Enums para valores limitados, Tuplas para estructuras de datos heterogéneas fijas y Arrays para colecciones.

    Setup Inicial

    Crea un archivo analizador.ts e incluye la función prompt.

    Tarea a realizar

    Estás programando el software para un laboratorio. Necesitas registrar experimentos realizados durante el día. Cada experimento consta del tipo de elemento analizado, su peso exacto y un código de seguridad. 1. Define un Enum llamado ElementType con los valores: WATER, EARTH, FIRE, AIR. 2. Define un tipo Tuple llamado ExperimentRecord. Debe contener exactamente: * Índice 0: El elemento (ElementType). * Índice 1: Cantidad en gramos (number). * Índice 2: Si es estable (boolean). 3. Crea un array vacío tipado para almacenar estos registros. 4. Pregunta al usuario: "¿Cuántos experimentos vas a registrar?". 5. Usa un bucle for para pedir los datos de cada uno. * Nota: Al leer el elemento (string), deberás convertirlo o asignarlo al Enum. 6. Al finalizar, recorre el array e imprime un informe de cada experimento. 7. Usa parseInt( ), parseFloat( ), variable.toLowerCase() si necesario.

    Flujo del Programa:

    Pregunta al usuario cuántos experimentos quiere registrar. <br/>
Usa un bucle para pedir los datos de cada experimento:<br/>
Pide el elemento (el usuario escribirá "WATER", "FIRE", etc.). Convierte el string al Enum correspondiente.<br/>
Pide la cantidad (número).<br/>
Pide si es estable (el usuario escribirá "si" o "no").<br/>
Guarda cada tupla en el array.<br/>
Al final, recorre el array e imprime un informe: "Experimento [X]: [Elemento] - [Cantidad]g - [Estable/Inestable]".<br/>

    Aplicación en el Mundo Real

    Las tuplas son ideales para filas de bases de datos o registros CSV donde la posición del dato indica qué es (Columna 1: Tipo, Columna 2: Valor), ahorrando la sobrecarga de crear un objeto completo con claves si no es necesario.

    VER Solución. 
    import * as fs from 'fs';

function prompt(question: string): string {
    fs.writeSync(1, Buffer.from(question, 'utf8'));
    const buf = Buffer.alloc(1024);
    const bytes = fs.readSync(0, buf, 0, 1024, null);
    return buf.toString('utf8', 0, bytes).trim();
}

// 1. Definición de Enum
enum ElementType {
    WATER = "Agua",
    EARTH = "Tierra",
    FIRE = "Fuego",
    AIR = "Aire"
}

// 2. Definición de Tuple
type ExperimentRecord = [ElementType, number, boolean];

// 3. Array de tuplas
const experiments: ExperimentRecord[] = [];

function main() {
    console.log("--- LABORATORIO QUÍMICO ---");
    const countStr = prompt("¿Cuántos experimentos vas a registrar? ");
    const count = parseInt(countStr) || 0;

    for (let i = 0; i < count; i++) {
        console.log(`\nRegistrando experimento #${i + 1}:`);

        // Lectura y conversión simple al Enum
        // En una app real, validaríamos que el input sea correcto
        const typeInput = prompt("Tipo (Agua/Tierra/Fuego/Aire): ");
        let type: ElementType = ElementType.WATER; // Valor por defecto

        if (typeInput.toLowerCase() === "tierra") type = ElementType.EARTH;
        else if (typeInput.toLowerCase() === "fuego") type = ElementType.FIRE;
        else if (typeInput.toLowerCase() === "aire") type = ElementType.AIR;

        const amount = parseFloat(prompt("Cantidad (g): "));
        const stableInput = prompt("¿Es estable? (si/no): ");
        const isStable = stableInput.toLowerCase() === 'si';

        // Guardamos la tupla
        const record: ExperimentRecord = [type, amount, isStable];
        experiments.push(record);
    }

    console.log("\n--- INFORME FINAL ---");
    experiments.forEach((exp, index) => {
        // Desestructuración de tupla para leer fácil
        const [elem, qty, stable] = exp;
        console.log(`Exp ${index + 1}: ${elem} | ${qty}g | Estado: ${stable ? 'Estable' : 'Inestable'}`);
    });
}

main();

    Ejercicios de Refuerzo

    2) Registro de Pacientes (Nulabilidad y Opcionales) | Nivel: Medio

    Objetivo

    Manejar correctamente la ausencia de datos utilizando propiedades opcionales (?) y el operador Nullish Coalescing (??).
    Contexto: Estás creando un sistema de admisión para una clínica. No todos los pacientes quieren dar todos sus datos, por lo que el sistema debe ser flexible y robusto ante la falta de información.

    Setup Inicial

    Crea un archivo pacientes.ts e incluye la función prompt.

    Tarea a realizar

    Sistema de admisión de una clínica donde no todos los datos son obligatorios. 1. Crea una Interface PatientProfile con: * id: number (obligatorio). * name: string (obligatorio). * age: number (opcional). * allergies: string (opcional). 2. Pide los datos al usuario. * Para age y allergies, si el usuario pulsa ENTER sin escribir nada, asigna undefined. 3. Crea el objeto paciente. 4. Imprime la ficha técnica. * Usa ?? para que si la edad no existe, muestre "Desconocida". * Usa ?? para que si no hay alergias, muestre "Ninguna". * (Opcional) Intenta usar Optional Chaining (?.) si decides meter los datos de contacto en un objeto anidado (ej: contact?.phone).

    Flujo del Programa:

    Solicita el ID y el Nombre (si el usuario lo deja vacío, debes obligarle a escribirlo o lanzar error).<br/>
Solicita la Edad (permite que el usuario pulse Enter sin escribir nada).<br/>
Solicita Alergias separadas por comas (permite que el usuario pulse Enter si no tiene).<br/>
Genera un objeto paciente con esos datos.<br/>
Imprime la Ficha del Paciente:<br/>
Nombre: (El introducido).<br/>
Edad: Si no introdujo nada, debe mostrar "Edad desconocida" o "0" usando ??.<br/>
Alergias: Si no introdujo nada, debe mostrar "Sin alergias conocidas".<br/>

    Aplicación en el Mundo Real

    En formularios web, el usuario a menudo deja campos vacíos. El backend debe distinguir entre "el usuario escribió 0" (edad válida) y "el usuario no escribió nada" (undefined/null). ?? es vital para no tratar el 0 como falso.

    VER Solución. 
    import * as fs from 'fs';

function prompt(question: string): string {
    fs.writeSync(1, Buffer.from(question, 'utf8'));
    const buf = Buffer.alloc(1024);
    const bytes = fs.readSync(0, buf, 0, 1024, null);
    return buf.toString('utf8', 0, bytes).trim();
}

interface PatientProfile {
    id: number;
    name: string;
    age?: number;      // Opcional
    allergies?: string; // Opcional
}

function main() {
    console.log("--- ADMISIÓN PACIENTES ---");

    const id = parseInt(prompt("ID Paciente: "));
    const name = prompt("Nombre completo: ");

    // Lógica para manejar vacíos como undefined
    const ageInput = prompt("Edad (Enter para omitir): ");
    const age = ageInput === "" ? undefined : parseInt(ageInput);

    const allergiesInput = prompt("Alergias (Enter para omitir): ");
    const allergies = allergiesInput === "" ? undefined : allergiesInput;

    const patient: PatientProfile = {
        id,
        name,
        age,
        allergies
    };

    console.log("\n--- FICHA GENERADA ---");
    console.log(`Paciente: ${patient.name} (ID: ${patient.id})`);

    // Uso de Nullish Coalescing
    console.log(`Edad: ${patient.age ?? "Desconocida"}`);
    console.log(`Alergias: ${patient.allergies ?? "Ninguna conocida"}`);
}

main();

    3) Calculadora de Envíos (Funciones y Rest Params) | Nivel: Medio

    Objetivo

    Implementar funciones con tipado explícito de argumentos y retorno, utilizando Rest Parameters (...args) para listas de longitud variable.

    Setup Inicial

    Crea un archivo logistica.ts e incluye la función prompt.

    Tarea a realizar

    Calculadora de costes logísticos con tarifas extra dinámicas. 1. Crea una función calculateShippingCost. 2. Argumentos: * weight (number). * distance (number). * ...extras (number[]). 3. Debe devolver number. Fórmula: (peso * distancia * 0.1) + suma_de_extras. 4. En el main: * Pide peso y distancia. * Pregunta cuántos cargos extra aplicar (Aduanas, Urgencia, Festivo...). * Lee los cargos en un bucle y guárdalos en un array. * Llama a la función usando el operador spread (...) para pasar el array como argumentos individuales, o pásalos según permita tu lógica.

    Flujo del Programa:

    Pide el peso del paquete (kg).<br/>
Pide la distancia (km).<br/>
Pregunta: "¿Cuántos cargos extra quieres añadir?".<br/>
En base a ese número, pide los cargos uno a uno.<br/>
Llama a la función pasando los extras mediante el operador spread (si los guardaste en un array) o directamente si los pasas uno a uno (aunque con prompt lo ideal es guardarlos en array y pasarlos con ...).<br/>
Muestra el coste total formateado (ej: "50.00 €").  <br/>

    Aplicación en el Mundo Real

    Los Rest Parameters son fundamentales para crear funciones de utilidad (como loggers o calculadoras) que aceptan un número infinito de argumentos sin obligar a crear un array explícito cada vez.

    VER Solución. 
    import * as fs from 'fs';

function prompt(question: string): string {
    fs.writeSync(1, Buffer.from(question, 'utf8'));
    const buf = Buffer.alloc(1024);
    const bytes = fs.readSync(0, buf, 0, 1024, null);
    return buf.toString('utf8', 0, bytes).trim();
}

// Función con Rest Parameters (...extras)
function calculateShippingCost(weight: number, distance: number, ...extras: number[]): number {
    const baseCost = weight * distance * 0.1;
    const extrasTotal = extras.reduce((total, current) => total + current, 0);
    return baseCost + extrasTotal;
}

function main() {
    console.log("--- LOGÍSTICA GLOBAL ---");

    const w = parseFloat(prompt("Peso del paquete (kg): "));
    const d = parseFloat(prompt("Distancia (km): "));

    const numExtras = parseInt(prompt("¿Cuántos cargos extra aplicar? "));
    const extrasList: number[] = [];

    for(let i=0; i<numExtras; i++) {
        const val = parseFloat(prompt(` > Importe extra #${i+1}: `));
        extrasList.push(val);
    }

    // Llamada usando Spread Operator para expandir el array en argumentos
    const total = calculateShippingCost(w, d, ...extrasList);

    console.log(`\nCOSTE TOTAL DEL ENVÍO: ${total.toFixed(2)} €`);
}

main();

    Ejercicios de Ampliación

    4) Sistema Domótico (POO, Herencia e Interfaces) | Nivel: Alto

    Objetivo

    Estructurar una aplicación usando Programación Orientada a Objetos, Clases Abstractas e Interfaces, interactuando con el usuario mediante un menú.
    Contexto: Vamos a domotizar una casa. Necesitamos modelar diferentes aparatos que comparten características pero funcionan diferente.

    Setup Inicial

    Crea un archivo domotica.ts e incluye la función prompt.

    Tarea a realizar

    1. Define una Interface Device con: name (string), turnOn() y turnOff().
    2. Crea una Clase Abstracta Appliance que implemente Device.
      • Propiedad protected isOn (boolean).
      • Constructor que reciba el nombre.
      • Implementa turnOn/turnOff cambiando el estado e imprimiendo un mensaje.
    3. Crea una Clase Hija Television que herede de Appliance.
      • Propiedad volume (number).
      • Método volumeUp(): Sube el volumen e imprime el nivel. Solo funciona si la TV está encendida (comprobar isOn).
      • Sobrescribe turnOn() para añadir un mensaje personalizado ("Logo de Samsung...").
    4. En el main:
      • Instancia una TV preguntando el nombre.
      • Crea un bucle while(true) con un menú: 1.Encender, 2.Apagar, 3.Volumen, 4.Salir.

    Flujo del Programa:

    Pide al usuario el nombre para su nueva Televisión.<br/>
Instancia el objeto Television.<br/>
Crea un pequeño menú interactivo (bucle while):<br/>
"1. Encender" -> Llama a turnOn().<br/>
"2. Apagar" -> Llama a turnOff().<br/>
"3. Subir Volumen" -> Llama a volumeUp().<br/>
"4. Salir".<br/>
El programa termina cuando el usuario elige la opción 4.<br/>

    Aplicación en el Mundo Real

    Este patrón es la base de frameworks backend como NestJS. Las interfaces definen contratos, las clases abstractas dan funcionalidad base y las clases concretas implementan la lógica de negocio específica.

    VER Solución. 
    import * as fs from 'fs';

function prompt(question: string): string {
    fs.writeSync(1, Buffer.from(question, 'utf8'));
    const buf = Buffer.alloc(1024);
    const bytes = fs.readSync(0, buf, 0, 1024, null);
    return buf.toString('utf8', 0, bytes).trim();
}

// 1. Interface
interface Device {
    name: string;
    turnOn(): void;
    turnOff(): void;
}

// 2. Clase Abstracta
abstract class Appliance implements Device {
    protected isOn: boolean = false;

    constructor(public name: string) {}

    turnOn(): void {
        this.isOn = true;
        console.log(`[${this.name}] -> Sistema Iniciado.`);
    }

    turnOff(): void {
        this.isOn = false;
        console.log(`[${this.name}] -> Apagando sistema.`);
    }
}

// 3. Clase Concreta
class Television extends Appliance {
    private volume: number = 10;

    // Sobrescritura de método
    turnOn(): void {
        super.turnOn(); // Llamamos al padre
        console.log("...Mostrando Logo de Bienvenida...");
    }

    volumeUp(): void {
        if (!this.isOn) {
            console.log("❌ Error: La TV está apagada.");
            return;
        }
        this.volume += 5;
        console.log(`🔊 Volumen subido al ${this.volume}%`);
    }
}

// 4. Lógica Principal
function main() {
    const tvName = prompt("Introduce el nombre de tu TV: ");
    const myTV = new Television(tvName);

    let exit = false;

    while (!exit) {
        console.log("\n--- CONTROL REMOTO ---");
        console.log("1. Encender");
        console.log("2. Apagar");
        console.log("3. Subir Volumen");
        console.log("4. Salir");

        const option = prompt("Selecciona una opción: ");

        switch (option) {
            case "1": myTV.turnOn(); break;
            case "2": myTV.turnOff(); break;
            case "3": myTV.volumeUp(); break;
            case "4": exit = true; break;
            default: console.log("Opción no válida");
        }
    }
    console.log("Mando desconectado.");
}

main();
