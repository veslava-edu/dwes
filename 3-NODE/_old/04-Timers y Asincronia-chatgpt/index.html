    ⏱️ Timers, Event Loop y Asincronía en Node.js (Parte 1)

    Introducción

    Imagina que Node.js es un restaurante con un solo camarero extremadamente eficiente. No cocina todos los platos a la vez, pero toma pedidos sin parar, delega lo pesado a cocina (libuv) y sirve cuando toca. Ese “cuándo toca” lo decide el Event Loop y, para medir tiempos y turnos, usamos Timers.

    Como vimos en Módulos principales de Node.js, Node no es rápido por magia, sino por cómo gestiona la asincronía. En este tema vamos a abrir el motor y ver qué pasa realmente cuando usamos setTimeout, Promises o async/await.

    1. Asincronía y modelo de ejecución en Node.js

    1.1 Programación síncrona vs asíncrona

    Definición

    Programación síncrona: cada operación bloquea la siguiente. Programación asíncrona: las operaciones largas se delegan y el programa continúa.

    En backend, bloquear es pecado mortal.

    Ejemplo 1 – Código síncrono (bloqueante)

    function bloqueante(): void {
  const inicio = Date.now();
  while (Date.now() - inicio < 3000) {}
  console.log('Fin de tarea');
}

console.log('Inicio');
bloqueante();
console.log('Esto espera');

    Ejemplo 2 – Código asíncrono con timer

    console.log('Inicio');

setTimeout((): void => {
  console.log('Fin de tarea');
}, 3000);

console.log('Esto NO espera');

    Ejemplo 3 – Simulación backend real

    setTimeout(() => {
  console.log('Respuesta enviada al cliente');
}, 1000);

console.log('Servidor sigue atendiendo peticiones');

    1.2 Non-blocking I/O

    Definición

    Non-blocking I/O permite que operaciones de entrada/salida se ejecuten sin detener el hilo principal.

    Ejemplo 1 – Lectura asíncrona simulada

    setTimeout(() => {
  console.log('Datos leídos del disco');
}, 500);

    Ejemplo 2 – Varias operaciones en paralelo

    setTimeout(() => console.log('DB'), 300);
setTimeout(() => console.log('API'), 100);
setTimeout(() => console.log('Cache'), 200);

    Ejemplo 3 – Backend concurrente

    console.log('Petición A');
setTimeout(() => console.log('Respuesta A'), 1000);
console.log('Petición B');

    4. Timers avanzados y control del Event Loop

    4.1 El objeto Timeout

    Definición

    En Node.js, setTimeout() y setInterval() no devuelven un número, sino un objeto Timeout, que permite controlar su relación con el Event Loop.

    Este objeto es clave en aplicaciones backend long-running (servidores, workers, demonios).

    Ejemplo 1 – Inspeccionando el objeto Timeout

    const timeout = setTimeout(() => {
  console.log('Ejecutado');
}, 1000);

console.log(timeout);

    Ejemplo 2 – Timeout como handle activo

    const timeout = setTimeout(() => {
  console.log('Sigo vivo');
}, 5000);

// El proceso NO termina mientras el timeout esté activo

    Ejemplo 3 – Uso real en servicios

    function startCleanupJob(): NodeJS.Timeout {
  return setTimeout(() => {
    console.log('Limpieza completada');
  }, 3000);
}

    4.2 ref(), unref() y hasRef()

    Definición

    Estos métodos permiten decidir si un timer mantiene vivo el Event Loop o no.

    Es como decirle a Node:

    “Esto es importante” (ref) “Esto no impide cerrar el programa” (unref)

    Ejemplo 1 – unref()

    setTimeout(() => {
  console.log('Puede que no se ejecute');
}, 5000).unref();

    Ejemplo 2 – ref()

    const timeout = setTimeout(() => {
  console.log('Garantizado');
}, 2000);

timeout.ref();

    Ejemplo 3 – hasRef()

    const t = setTimeout(() => {}, 1000);
console.log(t.hasRef()); // true

    Tip

    Ideal para tareas auxiliares como logs, métricas o heartbeats.

    7. Microtasks y prioridad de ejecución

    7.1 Macrotasks vs Microtasks

    Definición

    • Macrotasks: tareas “normales” gestionadas por el Event Loop (timers, I/O, setImmediate).
    • Microtasks: tareas de máxima prioridad, que se ejecutan antes de pasar a la siguiente fase.

    👉 En Node.js, las microtasks siempre se ejecutan antes que cualquier timer.

    Ejemplo 1 – Microtask gana siempre

    setTimeout(() => console.log('Timer'), 0);

Promise.resolve().then(() => {
  console.log('Promise');
});

    Ejemplo 3 – Microtasks encadenadas

    Promise.resolve().then(() => {
  console.log('Primera');
  Promise.resolve().then(() => console.log('Segunda'));
});

    Ejemplo 3 – Cálculo pesado

    function fibonacci(n: number): number {
  return n <= 1 ? n : fibonacci(n - 1) + fibonacci(n - 2);
}
